Trouble with that? Use your password instead

This older route asks for your Mozilla password so FireSync can derive an authentication value locally. The password is never sent to Mozilla in the clear and never stored, but FireSync does briefly handle it — which is exactly what the button above avoids. Prefer the button.

FireSync uses your password only to obtain a Sync token from Mozilla, then immediately destroys the session. Only a scoped refresh token and your Sync key are kept, encrypted with the passphrase from step 1.

  • Pin FireSync to the toolbar for quick unlocking.
